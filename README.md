> **小〜中学生向けネットリテラシー啓発ゲーム（加害者視点特定シミュレーター）**
大学の実習において、小〜中学生のネットリテラシー改善・啓発を目的として制作したUnityゲームです。
※本作は学内発表用の作品であり、一般リリースは行っておりません。
---
## 🎮 ゲーム概要
本作は、プレイヤーが「SNSで少女の特定を企む加害者」の視点となり、架空のWindows OS風インターフェースを操作しながら、SNS（Twitter、Instagramを模したもの）の投稿からヒントを集め、少女の現在地や個人情報を特定していくシミュレーションゲームです。
### 💡 制作の背景と教育的意図
従来のネットリテラシー教育（「個人情報を書き込まない」「怪しい人と関わらない」といったルール説明）では、子供たちが「自分には関係ない」と当事者意識を持ちにくい課題がありました。
そこで本作では、**「加害者側の視点をあえて体験する」**というアプローチを採用しました。
自分が何気なく投稿した写真やテキストが、悪意ある他者によってどのように分析され、特定の決定打になってしまうのかを逆説的に理解し、自分自身のSNSの使い方を見直すきっかけを提供することを目的としています。
---
## 🕹️ ゲームの流れと主なシステム
1. **架空のOS操作**
   - Unity上で構築されたWindows OS風のデスクトップ画面を操作します。
2. **SNSブラウジングによる情報収集**
   - ターゲットである少女のInstagramやTwitter（風のSNS）を閲覧。
   - 投稿画像内の背景（ランドマーク、電柱、標識など）や、テキストの内容、投稿時間などから、彼女の行動範囲や特定に繋がるヒントを探し出します。
3. **メモ帳・マップとの連携**
   - 見つけたヒントをゲーム内の「メモ帳」に記録し、「マップ」アプリにマッピングしていきます。
4. **特定と結末**
   - すべての情報を揃え、最終的に少女の居場所へ会いに行くことでゲームは終了します。
   - プレイヤーには「情報漏洩が招く最悪の結末（恐怖）」を強く実感させる演出となっています。
